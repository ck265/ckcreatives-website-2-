CK CREATIVES WEBSITE
====================

Files
-----
index.html          Main website page
css/style.css       All responsive styling
js/script.js        Mobile menu and portfolio category filters
images/             40 lightweight JPG sample artwork images + favicon.svg

HOW TO CUSTOMIZE
----------------
1. Open index.html in a code editor.
2. Replace the sample project images in images/ with your own JPGs.
   Keep the filenames project-01.jpg through project-40.jpg, or update the
   image paths in index.html to match your own filenames.
3. Search index.html for each sample project title and description to edit them.
4. Contact details are already set to:
   Email: ckdesign265@gmail.com
   Phone: 0987512721
   Facebook: https://www.facebook.com/profile.php?id=100068802026827
   Instagram: https://www.instagram.com/ckay_graphixx?dlrf=bHE1YXdtN240ZWs1
5. If you add a real booking URL, add it to the contact links or ask for a
   booking button to be added.
6. Open index.html in your browser to preview locally.

PUBLISHING
----------
Upload the whole ck_creatives_website folder to a static website host. Keep
index.html at the root and retain the css, js and images folders.

NOTE
----
The 40 JPGs are lightweight illustrative placeholders, not your original
client work. Replace them with your own portfolio images before presenting
the site as completed client work.


UPDATE: Portfolio artwork files are now standardized to 1800 x 1800 pixels. The website displays each image in a responsive square frame and preserves the full artwork without cropping. Replace the JPG files with your own square 1800 x 1800 designs for best results.

Portfolio image behavior update: artwork is now non-clickable and does not open a zoomed image. Each card keeps its category/title and short description below the square artwork. Images display in square 1:1 boxes.
